## How it works

`main.ts` (Node 22, standard library only) copies `entry.png` — the 1024×1024 poster — to `/output/entry.png`. It takes no input, makes no network requests, and is deterministic: two runs produce byte-identical output.

```sh
node main.ts
```

## The place

ERRANTA is a small whitewashed town with terracotta roofs and one tall slender spiral lighthouse, crowning a lush green island that drifts across a vast calm golden sea, following the sun.
